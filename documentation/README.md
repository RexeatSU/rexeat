Esta aplicación se llamará Rexeat (de "Rex", nuestra encantadora mascota, y "eat", porque eso es lo que hacemos aquí).

## ¿Qué es Rexeat?

Rexeat es una aplicación SaaS que ayuda a los restaurantes en sus operaciones diarias. Somos rápidos, fáciles y fiables. Pero, ¿qué significa esto?

- Rápido: Desarrollamos Rexeat desde el punto de vista de la psicología del usuario. No nos importa si es bonito, debe ser útil. Y aunque a veces ser útil es ser bonito, nuestro principal objetivo es hacer tu trabajo más sencillo.
- Fácil: Desarrollamos Rexeat con una interfaz simple e intuitiva, para que puedas usarla sin ningún entrenamiento previo.
- Fiable: Desarrollamos Rexeat con una arquitectura segura y estable, para que puedas usarla con la confianza de que en ningún momento fallará o te dejará tirado.

# Objetivos principales

- [ ] Página web para comensales para leer el menú con el toque de una tarjeta de marca.
  - [ ] Auto-traducción a cualquier idioma que puedas imaginar utilizando IA generativa.
- [ ] Página web para el personal del restaurante para gestionar el menú.
  - [ ] Inteligencia Artificial para hacer la mayor parte del trabajo duro por ti.
