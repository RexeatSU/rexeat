## 2. Roles

| Rol         | Responsabilidad                     |
| ----------- | ----------------------------------- |
| Propietario | Mantiene vigencia y aprueba cambios |
| Autor       | Redacta y actualiza el contenido    |
| Revisor     | Verifica contenido y consistencia   |
